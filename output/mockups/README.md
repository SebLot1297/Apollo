# CommandGrid mockup exploration

Three static Mission Control concepts for the hackathon project. No application source, behavior, or brand system is changed by this exploration.

- A — Spatial atlas: geographic map first, incident inspector alongside it.
- B — Civic systems: bright structured workspace with a system-health overview.
- C — Recovery sequence: incident history first with persistent recovery controls.

The same fictional scenario anchors each concept: Communications Recovery, elapsed 03:42 of 10:00, communications 82%, equipment 75%, power 64%, resources 58%, and a power failure at Juniper Power Station. All values, locations, effects, and additional annotations in the generated images are illustrative. Generated copy is not a specification or evidence of implemented behavior.

Guidance: https://github.com/pbakaus/impeccable (SKILL.md, new-work, shape, and visualize references). Inspiration: https://www.awwwards.com/ and https://www.awwwards.com/sites/lidar-drone-scanning. Applied hierarchy, complete application framing, distinctive composition, readable data, and task-focused recovery actions.

Images are generated with the built-in image_gen tool. GPT Image 2 was requested, but the tool exposes no model selector or verifiable model identifier; the exact model is unverified. No API fallback was used.

Prompt sidecars preserve the exact generation prompts. The user approved A for implementation across CommandGrid, with existing server data replacing unsupported sample fields. B and C remain unused alternatives. See `../../docs/atlas-implementation.md` for the working result and verification.
